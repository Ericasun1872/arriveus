# ArriveUS

한국인을 위한 미국 정착 가이드 웹사이트입니다.  
도메인: [getarriveus.com](https://getarriveus.com)

## 기능

- DMV, 은행, 의료, 세금, 취업, 주거 가이드
- 준비물 체크리스트, 영어 표현, 필기 연습 문제
- 주별 DMV 가이드 (시애틀/워싱턴주 포함)
- 즐겨찾기 (브라우저 저장)

## 로컬 실행

```bash
npm install
npm run dev
```

[http://localhost:3000](http://localhost:3000) 에서 확인합니다.

```bash
npm run build
```

## 스택

- Next.js (App Router)
- TypeScript
- Tailwind CSS

## 배포

Vercel에 이 저장소를 연결한 뒤 `getarriveus.com` 도메인을 프로젝트에 추가하면 됩니다.
